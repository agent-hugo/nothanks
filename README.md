# Нет, спасибо! — онлайн-версия No Thanks! для мобильных браузеров

Статичная страница для GitHub Pages. Связь и хранение состояния идут через MQTT-брокер flespi (retain-сообщения).

## Файлы
- `index.html` — интерфейс и сетевая часть (mqtt.js подключается с CDN unpkg).
- `game.js` — правила игры: раздача, ходы, подсчёт очков. Не зависит от сети, работает и в Node.

## Настройка flespi
1. Зайдите на flespi.io → Tokens → создайте токен.
2. В ACL токена разрешите только MQTT pub/sub на топики `nothanks/#`.
3. Либо впишите токен в `DEFAULT_TOKEN` в `index.html`, либо каждый игрок введёт его при входе (токен сохраняется в браузере).

## Публикация
Положите файлы в репозиторий → Settings → Pages → Deploy from branch (main, /root).

## Как играть
- «Создать комнату» → «Пригласить» (ссылка вида `...?room=ABCDE`).
- Когда в комнате 3–7 человек, любой нажимает «Начать партию».
- Тест в одном браузере: откройте вкладки с `&as=1`, `&as=2`, `&as=3` — это разные игроки.

## Как устроена синхронизация
- `nothanks/v1/<room>/p/<playerId>` (retain) — кто в комнате.
- `nothanks/v1/<room>/state` (retain) — полное состояние партии с номером версии `seq`.
- Хоста нет: игрок, чей ход, сам считает новое состояние и публикует его с `seq + 1`.
  Остальные принимают версию не старше текущей. Поэтому партия продолжается, даже если создатель комнаты закрыл вкладку.
- После переподключения (например, телефон выходил из сна) retain сразу возвращает актуальное состояние.
- «Удалить комнату» стирает retain-сообщения комнаты у брокера.

Колода лежит в состоянии открыто, а фишки соперников скрыты только в интерфейсе. Это игра на доверии между друзьями.
